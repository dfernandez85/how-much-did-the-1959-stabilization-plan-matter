# How Much Did the 1959 Stabilization Plan Matter? A Synthetic-Control Reassessment of Spain's Growth Acceleration

This repository contains the replication package for the article *How Much Did the 1959 Stabilization Plan Matter? A Synthetic-Control Reassessment of Spain's Growth Acceleration*. The project reproduces the econometric results reported in the main manuscript and the online appendix through a single synthetic-control pipeline. The current version is structured as a journal-ready replication package and exports only the final figures and tables cited in the paper.

## Quick start
From R:

```r
install.packages("renv")  # only if renv is not yet installed
renv::restore()
source("main.R")
```

From the terminal:

```powershell
Rscript main.R
```

The first run requires an internet connection. If the pinned PWT input is not present in `data/raw/`, `main.R` downloads it automatically and validates it against the versioned checksum stored in `data/raw/checksums.txt`.

## Repository structure
```text
R/
  config/         # Constants, package loading, and pipeline settings
  data/           # Data acquisition and preprocessing
  analysis/       # Estimation pipeline and final journal exports
  utils/          # General helper functions
  visualization/  # Plotting functions
scripts/
  fetch_data.R    # Forces a clean download of the pinned PWT input
output/
  sessions/<timestamp>/
    plots/
      main/       # Figures for the main manuscript
      appendix/   # Figures for the online appendix
    tables/
      main/       # Tables for the main manuscript
      appendix/   # Tables for the online appendix
    run_config.yml
    session_info.txt
main.R            # Main entry point
```

## Dependencies
- **R 4.5.x is required.** The version is pinned in `renv.lock` (4.5.1) and enforced at start-up by `check_r_version()` in `main.R`. R 4.6.x is *not* supported: its toolchain compiles C sources under C23 by default, which breaks several pinned dependencies (`cli`, `data.table`, among others). Older releases (4.4 and below) are untested against the lockfile.
- `renv`: run `renv::restore()` before executing `main.R`
- The packages listed in `R/config/packages.R`, loaded internally through `load_required_packages()`

## Data and reproducibility
- `main.R` is self-bootstrapping: if the required raw input is missing, the script downloads the pinned source file and validates it against the checksum versioned in `data/raw/checksums.txt`.
- If the downloaded file does not match the versioned checksum, the pipeline stops with an error rather than rewriting the checksum registry.
- The repository does not version raw binary data or generated outputs. The only raw input required by the current pipeline is recovered from its pinned upstream source, and all results are regenerated by running `main.R`.
- Required raw file:
  - `data/raw/pwt110.xlsx` (Penn World Table 11.0, `Data` sheet), checksum key `pwt110`
- Checksums are stored in `data/raw/checksums.txt` using the format `<key> <md5sum>` and are treated as fixed, versioned locks on the raw input.
- To force a clean re-download of the pinned input, run `Rscript scripts/fetch_data.R`.
- The repository includes a GitHub Actions workflow at `/.github/workflows/reproducibility-check.yml` that verifies a clean Windows run of `renv::restore()` and the full execution of `main.R`, and uploads the resulting output session as an artifact.

## Running the pipeline
```r
renv::restore()        # once per environment
source("main.R")       # from R / RStudio
# or
Rscript main.R         # from the terminal
```

After `renv::restore()`, no manual preparation of `data/raw/` is required; the pipeline bootstraps the required PWT input automatically when needed.

Each execution creates a new timestamped folder under `output/sessions/<timestamp>/`. The final visible output is restricted to `plots/main`, `plots/appendix`, `tables/main`, `tables/appendix`, plus `run_config.yml` and `session_info.txt`.

## Exported outputs
- `plots/main`: figures used in the main manuscript
- `plots/appendix`: figures used in the online appendix
- `tables/main`: tables used in the main manuscript
- `tables/appendix`: tables used in the online appendix
- `run_config.yml` and `session_info.txt`: reproducibility metadata for each session

### Correspondence with the manuscript
Exported files carry the number, the column layout, and the rounding of the table
as it appears in the paper. No table in the manuscript is assembled by hand from
several outputs.

| Manuscript | Exported file |
| --- | --- |
| Table 3. Baseline donor weights | `tables/main/Table_3_baseline_donor_weights.csv` |
| Table 4. Predictor balance | `tables/main/Table_4_predictor_balance.csv` |
| Table 5. Baseline fit, effect size, placebo inference | `tables/main/Table_5_baseline_fit_effect_size_and_placebo_inference.csv` |
| Table 6. Leave-one-donor-out robustness | `tables/main/Table_6_leave_one_donor_out_robustness.csv` |
| Table 7. Predictor-set robustness | `tables/main/Table_7_predictor_set_robustness.csv` |
| Table 8. Restricted donor pools | `tables/main/Table_8_restricted_donor_pools.csv` |
| Table 9. Pseudo-treatment dates | `tables/main/Table_9_pseudo_treatment_dates.csv` |
| Table 10. Counterfactual Spain in 1975 (SCM and PRS) | `tables/main/Table_10_counterfactual_1975_scm_and_prs.csv` |
| Figures 1-10 | `plots/main/Figure_<n>_*.png` |
| Appendix Table 5A. Observed and synthetic series | `tables/appendix/Table_5A_gdp_per_capita_observed_synthetic_series.csv` |
| Appendix Tables A1-A3, B1-B2, C1-C2, D1-D2 | `tables/appendix/Table_<id>_*.csv` |
| Appendix Figures A1-A2, B1-B2, C1-C2 | `plots/appendix/Figure_<id>_*.png` |

Table 10 is the only export that combines pipeline estimates with published
figures: the synthetic-control rows are computed from the session, while the
Prados de la Escosura, Roses, and Sanz-Villarroya (2012) scenario levels are
declared as literature constants in `R/analysis/journal_exports.R` with their
source in the surrounding comment.

## Module overview
- `R/analysis/synthetic_control.R`: prepares the panel, runs MSCMT, computes placebo exercises, fit filters, the stability gate, and the robustness specifications required by the paper
- `R/analysis/journal_exports.R`: takes the estimated objects and exports only the canonical figures and tables used in the manuscript and appendix; intermediate plot and table trees are removed at the end of the run so that each session remains clean

The authoritative, reproducible entry point for the project is `main.R`.
